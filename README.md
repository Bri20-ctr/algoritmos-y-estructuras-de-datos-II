## Descripción de los ejercicios
En este primer trabajo práctico, Herencias, Polimorfismo.

* **Ejercicio 1 (`tp1_ejercicio1.py`):** Armamos un sistema de transporte. Creamos una clase base llamada `Vehiculo` y dos clases hijas, `Auto` y `Moto`. Usamos el polimorfismo para que cada uno se describa a su manera.
* **Ejercicio 2 (`tp1_ejercicio2.py`):** Hicimos algo parecido pero con figuras geométricas. Creamos la clase `Figura` y después `Rectangulo` y `Circulo`. Cada uno calcula su propia área usando su fórmula.

## Cómo ejecutar los archivos
Para probar el código, tenés que abrir una terminal en esta carpeta donde esten estos archivo y para ejecutarlo, escribir:

1. Para el ejercicio 1:
   `python tp1_ejercicio1.py`

2. Para el ejercicio 2:
   `python tp1_ejercicio2.py`
